﻿# scrcpy-pad 使用说明

把电脑的键盘/鼠标映射成手机屏幕上的触控。画面由 scrcpy 本体窗口显示，本程序只负责注入触控。

## 快速上手

1. 手机开启 USB 调试并用数据线连接电脑。
2. 顶栏选设备 → **连接控制**（成功显示绿点）。
3. 左栏 **scrcpy 管理** 里指定 scrcpy 所在目录（不在程序同级时必做），勾选 **记住路径**。
4. **启动 scrcpy** 出画面 → **截取手机屏幕**。
5. 配置键位/轮盘 → 按 **总开关键（默认 F8）** 开启映射。

## 截图与取点

- **截取手机屏幕**：把当前手机画面抓进程序，之后所有取点都在它上面点。
- **取点**：点某个键位行的 **[取点]**，再点截图上的目标位置；圆点会落到那里。
- 取点、改键、修改响应范围三种操作**互斥**，以最后一次为准：正在改范围时点[取点]，会直接退出改范围转去取点。
- 点 **[新增]** 入列表后本次操作结束，不会停在取点状态；要修改再点该行的[取点]。
- 键位允许落在画面外，程序不做越界纠正。截图方向与当前坐标空间不一致时，画布上方会提示，重新截图即可。

## 按键映射

- **新增**：选类型 → 点按键按钮按物理键 →（点按/长按）取点 → **[新增]**。
- 鼠标左/中/右键也能直接绑定：捕获时按一下鼠标键即可。
- 行内可直接改：按键、坐标、**转长按/转点按**、**[取点]**、**[修改响应范围]**、**[删除]**。

### 点按 / 长按

- **点按**：按一下触发一次点击。时长填 0 = 按住不松手，再按一次同一键才抬起。
- **长按**：按住键盘期间触点一直按下，松开即抬起。两者可用[转长按]一键互切。

## 宏（开发中）

宏在独立的“宏”页面中设置，与键位映射、FPS 等功能并排。只有**可视化风格**的宏页提供自己的虚拟键盘：录制时点击虚拟键会写入步骤，非录制时点击虚拟键用于选择触发键。经典和鸿蒙风格只保留物理键录制/设置，不显示宏虚拟键盘。

宏分为两部分，可以单独使用，也可以组合：

- **录制宏**：记录按键的按下、抬起和时间间隔；默认只显示“事件数/约时长”的结果摘要，需要排查时打开 **[显示录制事件]**。键盘自动重复不会变成连续点击，长按会合并成一条按下和一条抬起，持续时间由两者间隔表示。
- **设置宏**：先用下拉选择“新增项目”的操作类型，再点 **[新增操作]**；支持按键、组合键、轮盘、FPS、点击、滑动、间隔或嵌套宏，并设置点按/长按、持续时间和间隔。
- **载入与取消**：载入已有宏后，[取消编辑] 会清空当前草稿，不影响原宏；已录宏展开时显示只读录制步骤和时长，设置动作才可编辑。
- **扩展宏**：可视化风格的录制和设置区都有 **[扩展宏...]**。窗口里可以继承已有键位组合，创建一套临时虚拟键盘/轮盘；保存后宏按虚拟键位执行并随宏保存，载入编辑时展开可见临时键位表；点 X 或取消则完全丢弃，不会改原数据。

宏触发键和普通键位一样参与“键位组合”切换：不同组合里的宏互不串用。虚拟键盘中宏键使用独立青绿色，点击宏键打开宏编辑，不会像空闲键一样新建普通键位。
## 响应范围

点按/长按键位有一个圆形响应范围（默认半径约 35px）。

1. 点该行的 **[修改响应范围]**，圆圈变黄。
2. 调大小，两种都行：按 `Ctrl++` / `Ctrl+-`，或**直接在截图上按住拖动**（按下处到圆心的距离就是半径）。
3. 点 **[完成]** 退出（整段修改算一步撤销）。

修改期间 `Ctrl+/-` 专用于圆圈，不会缩放整个界面；退出后恢复界面缩放。

## 轮盘（虚拟摇杆）

- **方向键**：四个方向各绑一个键（默认 WASD），八方向、松开回中。
- **取圆心**：点[取圆心]后在截图上点一下。新建轮盘的半径固定 **150px**，落点自动避开已有轮盘。
- **半径**：拖“半径”数值框，或点 **[改响应范围]** 后在截图上拖动 / 按 `Ctrl++` `Ctrl+-`。
- **方向模式**：`经典(标准)` 同轴反向会抵消；`灵敏(后按覆盖)` 让同一轴最后按下的方向覆盖较早方向。覆盖键先松开时，另一方向若仍按住会立即恢复，左右与上下分轴判断。
- **影响范围**：触点实际推出距离 = **半径 × 系数**（0.2~4.0，默认 1.0）。圈是给眼睛看的半径，系数才决定游戏里的手感。系数 ≠ 1.0 时截图上多画一圈橙色虚线表示真实推出距离，[影响范围复位] 一键回 1.0。
- **临时轮盘**：给轮盘设一个 **启用键**，该轮盘只在启用期间生效；“按住启用”或“再按切换”两种模式。
  - 松开启用键的**那一瞬间**，仍按着的键立刻恢复原功能，不必松手重按。
  - 例如：按住 K 连招途中按一下启用键再松开，K 会立刻回到原来的长按/系统键效果。
- **看方向键**：点一下截图上那个摇杆的圈 → 弹出信息卡（上/下/左/右 + 启用键），再点收起。画布上只标「摇杆N」。

轮盘类型：

- **标准四向**：原来的 WASD/四方向逻辑，可选经典或灵敏模式。
- **自定义方向**：方向数为 2～8，每个方向可以设置任意角度和一个按键；同时只接受最早按下的两个方向，移动方向取二者平均。
- **执行轮盘（开发中）**：按下方向键后，手指先从圆心落下，再按设定时长快速滑到目标方向。适合“点中心 + 滑动”才能释放的技能。

切到自定义/执行时，原标准四向数据仍保留；再切回标准不会丢失自定义方向。执行轮盘还可以调整中心范围圆和滑动时长。
## 滑动（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- 起点、终点分别点 **[取起点]** / **[取终点]** 在截图上取。
- 时长决定滑动耗时。
- **曲线**：默认(匀速) / 加速 / 减速 / 钟形 / 贝塞尔；点[设置...]改参数，窗口内会画出曲线预览。
- **轨迹**：默认(条形) / 方形 / 圆形；圆形可切换“视为直径/视为圆心”并另设出发点。
- 示例：王者荣耀里从屏幕右下划到左上 = 起点取右下、终点取左上、时长 200ms、曲线默认。

## 系统键（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- 注入 Android 系统按键，直接填 **keycode**。常用：返回 = 4、主页 = 3、最近任务 = 187。
- 示例：把 Esc 绑成 keycode 4 当返回键。

## 鼠标视角（FPS / 开放世界）（开发中）
- **拖动死区**：鼠标累计位移在死区内不移动手指，越过后才开始 `touch_move`。
- **边界**：有边界时到屏幕边缘就停；无边界时累积到“回转半径”会抬指、在锚点重按并保留余量，适合配合指针消隐做连续转向。
- **锚点**：锚点不是游戏准星，是虚拟手指的起点。默认不自动设置，请取在游戏 UI 之外的区域。

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

视角设置可以提前配置；真正按开关键进入模式时才会检查总映射是否开启，避免开打前抢走 Ctrl 等快捷键。

1. 展开 **鼠标视角**，勾选 **[启用鼠标视角]**，并选择 **[视角输入]**：触摸拖动（通用，默认）/ 虚拟手柄右摇杆（连续）/ 虚拟手柄右摇杆（分段回中）。旧版的 UHID/AOA 已移除，旧配置会自动迁移回触摸拖动，也不会再自动添加 `--mouse=uhid`。虚拟手柄模式会创建 Xbox 360 兼容 HID 手柄并驱动右摇杆，不产生触摸轨迹；游戏需要支持手柄右摇杆视角。面板自检会显示虚拟手柄是否已创建及输入报告数；分段模式会先保持摇杆极限一段时间再归中并携带超出量，减少 Android 合并 UHID 报告造成的丢转向。
2. 点 **[取锚点]**，在截图上的视角空白区取一点。
3. 给 **[视角模式开关键]** 绑定一个键；按它进入/退出视角模式。
4. 需要时设置 **[按住才退出]**：按住暂时退出 FPS、恢复普通映射并显示鼠标，松开自动返回。
5. **[指针消隐]** 默认开启。触摸拖动和虚拟手柄模式使用透明系统光标；退出 FPS 或按住“按住才退出”键时显示光标。
6. 勾选 **[开放世界模式]** 后不需要射击/开镜。触摸拖动使用无缝换手拖动带；虚拟手柄连续模式适合平滑追视角，分段回中模式在摇杆极限处自动归中并保留超出量，像一段一段滑屏。


- 普通键位行的 **[仅 FPS]**：勾选后该键只在 FPS 模式生效并显示，同键会覆盖普通映射；退出 FPS 自动释放并恢复仍按住的普通键。鼠标左/右/中键、侧键、滚轮都可按普通方式捕获；滚轮映射为 `BTN_WHEEL_UP/DOWN/LEFT/RIGHT`。
- FPS 专用键位继续支持点按、长按、滑动、系统键与截图取点。
- **灵敏度**、**视角移速**、**反转Y**、**归中**（静止 / 阈值 / 不归中）可调；视角移速同时作用于触摸拖动、开放世界和虚拟手柄右摇杆。
- 可绑 **[按住才瞄准]**（例如鼠标右键开镜）；**[指针消隐]** 默认开启，并在 FPS 模式内隐藏并锁定光标。
- 开打后按 `Ctrl+Alt` 把鼠标交还系统，再按一次收回。

### 组合键（可选）

- 在按键映射区勾选 **[启用组合键]** 后组合键才生效；关闭时设置保留但整体变灰失效。
- 第一个键是前缀键，其后键要与前缀同时按住。例如 `Ctrl+R` 应先按 Ctrl 再按 R。
- 前缀有单键动作时使用 45ms 快速判定；没有单键动作时使用 120ms，减少误触。完整组合会吞掉组件单键，避免先触发 FPS 开关或其它动作。

## 外观（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- **配色**：深色 / 浅色 / Nord / Catppuccin；**密度**：紧凑 / 标准 / 宽松。
- **背景图**：选图后可调铺满/完整/平铺、暗化遮罩与面板不透明度。选图后若几乎看不见，程序会自动把不透明度/压暗调到可见档位并写日志。
- **键位自动对比**（默认开）：按截图逐块采样，自动决定每处键位/摇杆用深色还是浅色，并给圈描一圈反相外套、给文字垫半透明衬底。
- **键位显示亮度**：在自动结果上微调（左加深、右变浅）；关掉自动对比后它就是固定档位。
- 外观改动除了随配置保存，还会自动写入同目录的 `look.json`，重启后保持，不必每次重调。

## 界面风格（主题）

- **[外观] → 界面风格** 三选一：**默认**（原有布局）/ **鸿蒙**（照 `harmonyos-pc` 那套浅色 UI 重新设计的界面：白底顶栏 + 左侧图标导航 + 中央白卡片页 + 右侧屏幕预览 + 底部状态栏）/ **可视化**（虚拟键盘取键）。
- **默认 / 可视化**风格下，配色（深色 / 浅色 / Nord / Catppuccin）、面板不透明度、背景图都保留；**鸿蒙是一套完整的浅色界面**，不再跟随深色配色。
- **切换会关一下再开**：风格牵动整体布局（按键布局、信息显示都会变），不能像配色那样即时生效 —— 选好后窗口自动关闭并立刻用新风格重新打开。风格写入 `look.json`，**下次启动还是上次选的主题**；**切换按键组合也不会把主题带走**。

### 可视化风格怎么用
虚拟键盘下方的“新增项目”可以选择：键位映射、组合键映射、摇杆映射、准星/瞄准锚点。组合键先点第一个键再点第二个键；轮盘会直接展开轮盘设置；准星用于展开 FPS/锚点设置。

- 中央是一张**老式机械键盘外观**的标准美式全键盘（深色机身 + 灰色键帽 + 鲜明描边，含导航区与小键盘），右边是虚拟鼠标（左右/中/侧键/滚轮上下）。
- **点空闲键** = 给这个键新建键位，并立刻进入截图取点（和以前一样在右下截图上点目标位置）；取点中该键呼吸闪烁，点操作栏的 **[取消取点]** 可放弃。
- **点已设置的键** = 选中它（高亮 + 白描边），键盘下方出现操作栏：取点 / 改键 / 转长按 / 修改响应范围 / 删除 / 仅FPS 等都在，与列表里改**完全一样**（列表也还在，用哪种方式都行）；先点 [取点] 再按老流程操作也可以。
- 键的颜色代表用途：键位=绿、宏=青绿、仅FPS=橙、摇杆方向=青/品红（永久/临时）、临时轮盘启用键=黄色、组合键与切换键=蓝、FPS 瞄准三键与总开关键=红；没设置的键是半透明灰键帽 + 亮点描边（看得见，又不挡住底下界面）。
- **键位页与 FPS 页的显示能力一样**：两页都有 显示按键映射 / 显示宏 / 显示组合键映射 / 显示摇杆 / 显示FPS 五个勾选；区别只是默认值 —— **FPS 页默认只显示"仅 FPS"键位**，想看普通映射/宏/组合键/摇杆自己勾上即可。FPS 页只能**编辑** FPS 相关键（仅FPS 键位、宏、瞄准三键），点普通键会给提示。
- **FPS 页只新增 FPS 独有项**：FPS 页的“新增项目”只保留 FPS 专用键位和瞄准锚点；普通键位、组合键、摇杆只可查看，点击不会修改。鼠标/锚点等 FPS 设置从同一操作区展开。
- 虚拟键盘只允许直接编辑**临时轮盘的方向键**；实体轮盘方向键和轮盘启用键必须在“摇杆映射”页修改，避免误设置和冲突。
- 标签页：右侧为 **键位 / 宏 / FPS 设置 / 其他功能**；左栏中部为 **键位组合 / 外观 / 诊断**（默认选中"键位组合"，启动即可设置键位）。都采用"浏览器标签页"式的方形按钮。

### 鸿蒙风格怎么用

- 整体是一套照 HDC 应用重排的浅色界面：**顶栏**（标题 + 设备 + 状态 pill + 主操作）、**左侧导航**、**中央卡片页**、**右侧"屏幕预览"**、**底部状态栏**（最新日志 + 引擎状态）。
- 左侧导航七页：**连接与设备**（设备/连接/启动 scrcpy/三件套路径）、**按键映射**（配置 + 键位列表 + 组合键）、**宏**、**虚拟轮盘**、**FPS 模式**（鼠标瞄准，内容直接展开）、**外观**、**诊断**（自检 + 运行日志）；导航底部是 撤销 / 重做 / 关于。
- 右侧"屏幕预览"就是截图取点区，宽度可拖动；顶栏右上角是 使用说明 / 刷新设备 / 连接控制 / 保存配置。

## 配置与文件

- 键位配置：默认 `~/.config/scrcpy-pad/profile.yaml`（Windows 为用户配置目录下同名文件）。
- **保存配置** / **另存为...** / **选用配置...** / **新建配置...** / **默认配置** / **检测当前 yaml**。
- **默认配置**：一键切回程序默认的配置文件（上面那个默认路径，首次运行时由程序自动创建）并加载它；该文件被删掉时会按出厂默认重新写一份。切过去之后，配置区下方那行"当前配置文件"会显示" (默认)"。
- 坐标按**比例**保存，换分辨率或换手机后键位自动对齐；旧版像素坐标只在尺寸确实装得下时才自动换算。
- `settings.json`：scrcpy / server / adb 路径、启动参数、上次设备、诊断日志级别（与 profile.yaml、look.json 同目录）。
- `diagnostics.log`：诊断日志，与上面几个文件同目录，**每次启动整体重写**。见下面的"诊断与排错"。

## 诊断与排错

- 左栏 **[诊断]** 面板做两件事：**告诉你现在哪里不通**，以及**把现场证据拿出来**。
- **状态自检**逐条打勾：输入捕获是否启动、有没有鼠标类设备、控制通道是否连上、映射是否开启、有没有因为触点池满而被放弃的按下。第一项 ✗ 时下面会给一句"现在不完整，因为……"。
- **诊断日志级别**：`error` / `warn` / `info`（默认）/ `debug` / `trace`。排查偶发问题时改成 `debug` 或 `trace`，复现一次，再看日志。改这个下拉框会同时写进 `settings.json` 的 `log_level`，所以重启后仍然生效；环境变量 `SCRCPY_PAD_LOG` 优先于它（临时排查不想改文件时用它）。
- **[打开日志目录]**、**[复制日志路径]**、**[显示日志末尾]**、**[导出诊断报告]**。导出会把"环境快照 + 当前配置摘要 + 日志全文"合成一个 `diagnostics-report-*.txt`，直接发这个文件就行。
- 日志里每一行是 `[+相对启动毫秒][本地时间][级别][模块][线程] 消息`。**相对时间**用来分析延迟与竞态，**本地时间**可以直接和 `journalctl`（Linux）或事件查看器（Windows）对齐。
- 启动时会打印一份**环境快照**：发行版与内核、会话类型（Wayland 还是 X11）、当前用户与所属组（会明确写出**是否在 `input` 组**）、配置目录与三个配置文件是否存在、显示器。几乎所有"我这儿不行你那儿行"的问题，答案都在这几行里。
- 还会打印**全部输入设备的清单与判定结论**（名字、总线/厂商号、键数量、判定成键盘还是鼠标、有没有打不开的）。外接键盘不工作时，先看它在不在清单里、以及有没有在同一行给出 `errno`。
- 日志里出现"**权威对账**"字样时，说明底层漏掉了某个松键事件，程序已经自动补发抬起防止卡键 —— 这也是"某个键过一会儿短暂失灵"这类现象的自愈记录。
- 日志里出现"**控制通道不可用: 已清空本地触点状态**"时，说明通道断过；现在不会再像以前那样把触点预算一直占着（以前必须按一次总开关键才能恢复）。
- 上一份日志如果**没有以正常退出标记结尾**，下次启动会明确提示"上次是崩溃或被强杀"，便于判断问题是否与崩溃有关。崩溃还会连线程名、出错位置与调用栈一起记下来。

## 按键组合与切换键位

- 一份 `profile.yaml` 里可以放**多套按键组合**。每套组合的内容与行为完全一致：各自有自己的键位、摇杆、瞄准、外观设置。切换组合等于整套换车。
- 左栏 **[按键组合 / 切换键位]** 里可以：选中哪套生效、给组合改名、`新建组合`（复制当前这套并切过去）、删除组合。至少保留一套。
- **切换键位**：新增一行后点左侧按键按钮（显示“按任意键...”），按下目标物理键即可绑定；右侧下拉选择“切换到哪一套”。之后按一下该键，整套组合切换（按住不放只触发一次）。
- 切换键属于**功能键**（与总开关键同级）：按下它不会触发任何普通绑定。它优先于普通键位，但让位给总开关键。
- 切换键本身也保存在 `profile.yaml` 的 `switch_keys` 里；`active` 记录上次生效的是哪一套，下次启动直接沿用。
- 文件头有一段注释写明了全部字段含义（包括动作的四种 YAML 写法），要手改的话照着改即可。

## scrcpy 管理与路径记忆

- 最省事的做法：在 **scrcpy 管理** 里填/选 scrcpy 所在**目录**，其余（server、adb）会自动补齐。
- 也可以只填其中一个文件，其余留空自动从同目录补齐；另有[自动寻找全部]、[测试并刷新]。
- 勾选 **记住路径** 后写入 `settings.json`，下次启动直接沿用，不必重新寻找。
- 路径被搬走也不会丢：程序会记住它原来所在目录，下次启动在那附近重新找回。
- 点 **[打开配置目录]** 可在文件管理器里查看这几个文件。
- 启动 scrcpy 时，程序会记录完整命令、自动追加参数、stdout、stderr 和退出码到 `diagnostics.log`，并把关键输出同步到左侧日志区。

## 引擎状态与触点

- 左栏显示“引擎: 触点 n/10 · 因触点池满被放弃 N 次”。
- 设备端同时最多认 **10 个触点**（键位 + 摇杆 + 瞄准共用一个池子），超出的按下会被设备直接丢弃，表现为“按了没反应”。这个计数不为 0 时，同时按的键少几个即可，括号里会写明是哪个键。
- **映射状态**：总开关键或顶栏 `映射: 开/关` 的每一次切换都会写进日志。按键不反应时先看日志是不是映射被关了。

## 快捷键

- `Ctrl+Z` 撤销 / `Ctrl+Y` 重做
- `Ctrl+S` 保存配置 / `Ctrl+Shift+S` 另存为
- `F5` 刷新设备
- `Ctrl++` / `Ctrl+-` 修改响应范围 / 轮盘半径时缩放当前圆圈

键位捕获、截图取点、输入文字时快捷键不生效，方便这些键当作待绑定键。

## 视角输入与注意事项

- 触摸拖动：兼容性最好，但本质是在屏幕上制造手指轨迹。轨迹经过游戏按钮、轮盘或手势区域时可能触发副作用，应把锚点放在干净区域。
- UHID/AOA 已从界面移除：旧版本自动写入的 `--mouse=uhid` / `--mouse=aoa` 会在启动时从参数框清除并写入日志。需要手动实验相对鼠标时请自行编辑 scrcpy 参数，并确认鼠标捕获风险。
- 指针消隐在触摸拖动和虚拟手柄模式下使用透明系统光标，切换焦点到 scrcpy 也会隐藏；若程序被强制结束留下透明光标，重新启动本程序会自动恢复。
- 视角设置可在映射前配置；真正按视角模式开关键时，只有总映射已开启才允许进入。

**重要结论：** UHID/AOA 都不适合作为默认自动方案：UHID 会接管鼠标/键盘焦点，AOA 与 ADB/USB 调试通常不能共用连接。本版已从界面移除自动启用；只认触摸的游戏仍需用触摸拖动兜底，虚拟手柄右摇杆适用于支持手柄视角的游戏。要做到完全无副作用，需要游戏自身支持鼠标/手柄视角，或设备端获得系统签名/特权能力做专用注入。

## 界面布局与调试信息

- 右侧主体使用四个选项卡：**键位映射**（含组合键）、**摇杆映射**、**FPS 功能**、**其他功能**；默认选中键位映射。
- **截图取点**固定在右侧主体最下方，不会被键位/摇杆设置顶下去；初始预览会按窗口宽度/高度自动适配，竖屏不再铺满右侧、横屏也不会顶出可视区域。按钮旁的 `+`、`-` 控制手动倍率，**重置** 回到自动适配。
- **其他功能 → 鼠标消隐**：可以给“隐藏/显示系统鼠标”绑定一个切换键，不受 FPS 或普通模式限制；再搭配“立即隐藏/显示鼠标”按钮使用。
- **其他功能 → 切换键位**：设置一个或两个键的快速切换组合，可指定目标组合、正向循环或反向循环；组合键顺序无关。是否真正启用由“按键组合”里的 **[启用快速切换]** 决定，未启用时设置仍保留。
- **显示过滤**：截图取点和可视化虚拟键盘的“显示项目”都是多选下拉，选项带对勾，点击后下拉暂时不关闭；默认显示按键映射、组合键、永久/临时摇杆，宏和 FPS 默认不选。
- **其他功能 → 调试信息**：勾选后显示手机帧率/刷新率、手机分辨率，可手动刷新并约每秒自动刷新；**悬浮显示**会打开置顶小窗口，覆盖在 scrcpy 窗口上方查看。

## 常见问题

- **提示“输入捕获不可用/无权限”**：执行 `sudo usermod -aG input $USER` 后注销重登，或用 `sg input -c './启动.sh'` 临时运行（仅 Linux）。
- **连接控制失败**：确认 `adb devices` 能看到设备，且 scrcpy-server 路径存在；在左栏手动指定 scrcpy 目录。
- **按键没反应**：① 看顶栏 `映射: 开/关` 是否被关了（日志有记录）；② 看引擎状态里“被放弃”是否为 0；③ 在别的窗口待过一会儿的话，按一次键会自动重新确认坐标空间。
- **外接键盘没反应**：打开 [诊断] 看设备清单里有没有它、以及有没有打不开的 `errno`。程序会定期重扫输入设备，插上后最多等约 2 秒就会自动接管，不必重启程序；拔掉再插上同样会自动恢复。
- **切窗口之后操作失灵，要重新开一次映射**：这是老版本的已知问题，已经修好（通道断开时会清空本地触点状态，重连时按当前按键状态重建）。若仍遇到，请把诊断日志级别改成 `debug` 复现一次，并导出诊断报告。
- **鼠标瞄准（FPS）没反应**：先看面板里的“生效条件自检”哪一项是 ✗；最常见的是尚未绑定 **[FPS 开关键]** 或尚未进入 FPS。注意**触摸板不能用于瞄准**（它没有相对位移轴），需要接鼠标或使用指点杆。
- **说不清原因的问题**：见上面的 [诊断与排错] —— 改 `debug` 级别复现一次，然后导出诊断报告。
- **画的圈看不清**：[外观] 里确认 **键位自动对比** 已开，再用 **键位显示亮度** 微调。
- **想打字**：按 F8 关闭映射即可。
## 组合键取点与任务取消

组合键动作支持点按、长按、滑动、系统键和仅 FPS。点按/长按有[取点]，滑动有[取起点]/[取终点]/[取出发点]及曲线、轨迹设置。

连接、截图、刷新、宏录制、取点、按键捕获等只要进入等待状态，界面会显示取消按钮。日志高度通过标题下方可拖动的分隔条调节，也可点[弹窗查看]打开独立可缩放日志窗口。
