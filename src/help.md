# scrcpy-pad 使用说明

把电脑的键盘/鼠标映射成手机屏幕上的触控。画面由 scrcpy 本体窗口显示，本程序只负责注入触控。

## 快速上手

1. 手机开启 USB 调试并用数据线连接电脑。
2. 顶栏选设备 → **连接控制**（成功显示绿点）。
3. 左栏 **scrcpy 管理** 里指定 scrcpy 所在目录（不在程序同级时必做），勾选 **记住路径**。
4. **启动 scrcpy** 出画面 → **截取手机屏幕**。
5. 配置键位/轮盘 → 按 **总开关键（默认 F8）** 开启映射。

## 截图与取点

- **截取手机屏幕**：把当前手机画面抓进程序，之后所有取点都在它上面点。
- **取点**：点某个键位行的 **[取点]**，再点截图上的目标位置；圆点会落到那里。
- 取点、改键、修改响应范围三种操作**互斥**，以最后一次为准：正在改范围时点[取点]，会直接退出改范围转去取点。
- 点 **[添加]** 入列表后这次操作就结束了，不会停在取点状态；要改再点该行的[取点]。
- 键位允许落在画面外，程序不做越界纠正。截图方向与当前坐标空间不一致时，画布上方会提示，重新截图即可。

## 按键映射

- **新增**：选类型 → 点按键按钮按物理键 →（点按/长按）取点 → **[添加]**。
- 鼠标左/中/右键也能直接绑定：捕获时按一下鼠标键即可。
- 行内可直接改：按键、坐标、**转长按/转点按**、**[取点]**、**[修改响应范围]**、**[删除]**。

### 点按 / 长按

- **点按**：按一下触发一次点击。时长填 0 = 按住不松手，再按一次同一键才抬起。
- **长按**：按住键盘期间触点一直按下，松开即抬起。两者可用[转长按]一键互切。

## 响应范围

点按/长按键位有一个圆形响应范围（默认半径约 35px）。

1. 点该行的 **[修改响应范围]**，圆圈变黄。
2. 调大小，两种都行：按 `Ctrl++` / `Ctrl+-`，或**直接在截图上按住拖动**（按下处到圆心的距离就是半径）。
3. 点 **[完成]** 退出（整段修改算一步撤销）。

修改期间 `Ctrl+/-` 专用于圆圈，不会缩放整个界面；退出后恢复界面缩放。

## 轮盘（虚拟摇杆）

- **方向键**：四个方向各绑一个键（默认 WASD），八方向、松开回中。
- **取圆心**：点[取圆心]后在截图上点一下。新建轮盘的半径固定 **150px**，落点自动避开已有轮盘。
- **半径**：拖“半径”数值框，或点 **[改响应范围]** 后在截图上拖动 / 按 `Ctrl++` `Ctrl+-`。
- **方向模式**：`经典(标准)` 同轴反向会抵消；`灵敏(后按覆盖)` 让同一轴最后按下的方向覆盖较早方向。覆盖键先松开时，另一方向若仍按住会立即恢复，左右与上下分轴判断。
- **影响范围**：触点实际推出距离 = **半径 × 系数**（0.2~4.0，默认 1.0）。圈是给眼睛看的半径，系数才决定游戏里的手感。系数 ≠ 1.0 时截图上多画一圈橙色虚线表示真实推出距离，[影响范围复位] 一键回 1.0。
- **临时轮盘**：给轮盘设一个 **启用键**，该轮盘只在启用期间生效；“按住启用”或“再按切换”两种模式。
  - 松开启用键的**那一瞬间**，仍按着的键立刻恢复原功能，不必松手重按。
  - 例如：按住 K 连招途中按一下启用键再松开，K 会立刻回到原来的长按/系统键效果。
- **看方向键**：点一下截图上那个摇杆的圈 → 弹出信息卡（上/下/左/右 + 启用键），再点收起。画布上只标「摇杆N」。

## 滑动（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- 起点、终点分别点 **[取起点]** / **[取终点]** 在截图上取。
- 时长决定滑动耗时。
- **曲线**：默认(匀速) / 加速 / 减速 / 钟形 / 贝塞尔；点[设置...]改参数，窗口内会画出曲线预览。
- **轨迹**：默认(条形) / 方形 / 圆形；圆形可切换“视为直径/视为圆心”并另设出发点。
- 示例：王者荣耀里从屏幕右下划到左上 = 起点取右下、终点取左上、时长 200ms、曲线默认。

## 系统键（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- 注入 Android 系统按键，直接填 **keycode**。常用：返回 = 4、主页 = 3、最近任务 = 187。
- 示例：把 Esc 绑成 keycode 4 当返回键。

## 鼠标瞄准（FPS）（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

用鼠标位移拖动游戏里的视角。FPS 模式有独立开关，不要求总开关键同时打开。

1. 展开 **鼠标瞄准(FPS)**，勾选 **[启用鼠标瞄准]**。
2. 点 **[取锚点]**，在截图上的视角空白区取一点。
3. 给 **[FPS 开关键]** 绑定一个键；按它进入/退出 FPS。
4. 需要时设置 **[临时退出键]**：按住暂时退出 FPS 并显示鼠标，松开自动返回。
5. 勾选 **[进入 FPS 时隐藏系统光标]** 决定进入 FPS 时是否隐藏指针。


- 普通键位行的 **[仅 FPS]**：勾选后该键只在 FPS 模式生效并显示，退出 FPS 自动抬起。鼠标左/右/中键、侧键、滚轮都可按普通方式捕获；滚轮映射为 `BTN_WHEEL_UP/DOWN/LEFT/RIGHT`。
- FPS 专用键位继续支持点按、长按、滑动、系统键与截图取点。
- **灵敏度**、**反转Y**、**归中**（静止 / 阈值 / 不归中）可调。
- 可绑 **[按住才瞄准]**（例如鼠标右键开镜）；**[进入 FPS 时隐藏系统光标]** 可独立控制进入 FPS 后是否隐藏并锁定光标。
- 开打后按 `Ctrl+Alt` 把鼠标交还系统，再按一次收回。

## 外观（开发中）

注意，本功能处于开发阶段，实际应用效果可能与描述有出入。

- **配色**：深色 / 浅色 / Nord / Catppuccin；**密度**：紧凑 / 标准 / 宽松。
- **背景图**：选图后可调铺满/完整/平铺、暗化遮罩与面板不透明度。选图后若几乎看不见，程序会自动把不透明度/压暗调到可见档位并写日志。
- **键位自动对比**（默认开）：按截图逐块采样，自动决定每处键位/摇杆用深色还是浅色，并给圈描一圈反相外套、给文字垫半透明衬底。
- **键位显示亮度**：在自动结果上微调（左加深、右变浅）；关掉自动对比后它就是固定档位。
- 外观改动除了随配置保存，还会自动写入同目录的 `look.json`，重启后保持，不必每次重调。

## 配置与文件

- 键位配置：默认 `~/.config/scrcpy-pad/profile.yaml`（Windows 为用户配置目录下同名文件）。
- **保存配置** / **另存为...** / **选用配置...** / **新建配置...** / **默认配置** / **检测当前 yaml**。
- **默认配置**：一键切回程序默认的配置文件（上面那个默认路径，首次运行时由程序自动创建）并加载它；该文件被删掉时会按出厂默认重新写一份。切过去之后，配置区下方那行"当前配置文件"会显示" (默认)"。
- 坐标按**比例**保存，换分辨率或换手机后键位自动对齐；旧版像素坐标只在尺寸确实装得下时才自动换算。
- `settings.json`：scrcpy / server / adb 路径、启动参数、上次设备、诊断日志级别（与 profile.yaml、look.json 同目录）。
- `diagnostics.log`：诊断日志，与上面几个文件同目录，**每次启动整体重写**。见下面的"诊断与排错"。

## 诊断与排错

- 左栏 **[诊断]** 面板做两件事：**告诉你现在哪里不通**，以及**把现场证据拿出来**。
- **状态自检**逐条打勾：输入捕获是否启动、有没有鼠标类设备、控制通道是否连上、映射是否开启、有没有因为触点池满而被放弃的按下。第一项 ✗ 时下面会给一句"现在不完整，因为……"。
- **诊断日志级别**：`error` / `warn` / `info`（默认）/ `debug` / `trace`。排查偶发问题时改成 `debug` 或 `trace`，复现一次，再看日志。改这个下拉框会同时写进 `settings.json` 的 `log_level`，所以重启后仍然生效；环境变量 `SCRCPY_PAD_LOG` 优先于它（临时排查不想改文件时用它）。
- **[打开日志目录]**、**[复制日志路径]**、**[显示日志末尾]**、**[导出诊断报告]**。导出会把"环境快照 + 当前配置摘要 + 日志全文"合成一个 `diagnostics-report-*.txt`，直接发这个文件就行。
- 日志里每一行是 `[+相对启动毫秒][本地时间][级别][模块][线程] 消息`。**相对时间**用来分析延迟与竞态，**本地时间**可以直接和 `journalctl`（Linux）或事件查看器（Windows）对齐。
- 启动时会打印一份**环境快照**：发行版与内核、会话类型（Wayland 还是 X11）、当前用户与所属组（会明确写出**是否在 `input` 组**）、配置目录与三个配置文件是否存在、显示器。几乎所有"我这儿不行你那儿行"的问题，答案都在这几行里。
- 还会打印**全部输入设备的清单与判定结论**（名字、总线/厂商号、键数量、判定成键盘还是鼠标、有没有打不开的）。外接键盘不工作时，先看它在不在清单里、以及有没有在同一行给出 `errno`。
- 日志里出现"**权威对账**"字样时，说明底层漏掉了某个松键事件，程序已经自动补发抬起防止卡键 —— 这也是"某个键过一会儿短暂失灵"这类现象的自愈记录。
- 日志里出现"**控制通道不可用: 已清空本地触点状态**"时，说明通道断过；现在不会再像以前那样把触点预算一直占着（以前必须按一次总开关键才能恢复）。
- 上一份日志如果**没有以正常退出标记结尾**，下次启动会明确提示"上次是崩溃或被强杀"，便于判断问题是否与崩溃有关。崩溃还会连线程名、出错位置与调用栈一起记下来。

## 按键组合与切换键位

- 一份 `profile.yaml` 里可以放**多套按键组合**。每套组合的内容与行为完全一致：各自有自己的键位、摇杆、瞄准、外观设置。切换组合等于整套换车。
- 左栏 **[按键组合 / 切换键位]** 里可以：选中哪套生效、给组合改名、`新建组合`（复制当前这套并切过去）、删除组合。至少保留一套。
- **切换键位**：添加一行后点左边的按键按钮（显示"按任意键..."），按下想用的物理键即可绑定；右边下拉选择"切到哪一套"。之后按一下这个键，整套组合就换过去（按住不放只算一次）。
- 切换键属于**功能键**（与总开关键同级）：按下它不会触发任何普通绑定。它优先于普通键位，但让位给总开关键。
- 切换键本身也保存在 `profile.yaml` 的 `switch_keys` 里；`active` 记录上次生效的是哪一套，下次启动直接沿用。
- 文件头有一段注释写明了全部字段含义（包括动作的四种 YAML 写法），要手改的话照着改即可。

## scrcpy 管理与路径记忆

- 最省事的做法：在 **scrcpy 管理** 里填/选 scrcpy 所在**目录**，其余（server、adb）会自动补齐。
- 也可以只填其中一个文件，其余留空自动从同目录补齐；另有[自动寻找全部]、[测试并刷新]。
- 勾选 **记住路径** 后写入 `settings.json`，下次启动直接沿用，不必重新寻找。
- 路径被搬走也不会丢：程序会记住它原来所在目录，下次启动在那附近重新找回。
- 点 **[打开配置目录]** 可在文件管理器里查看这几个文件。

## 引擎状态与触点

- 左栏显示“引擎: 触点 n/10 · 因触点池满被放弃 N 次”。
- 设备端同时最多认 **10 个触点**（键位 + 摇杆 + 瞄准共用一个池子），超出的按下会被设备直接丢弃，表现为“按了没反应”。这个计数不为 0 时，同时按的键少几个即可，括号里会写明是哪个键。
- **映射状态**：总开关键或顶栏 `映射: 开/关` 的每一次切换都会写进日志。按键不反应时先看日志是不是映射被关了。

## 快捷键

- `Ctrl+Z` 撤销 / `Ctrl+Y` 重做
- `Ctrl+S` 保存配置 / `Ctrl+Shift+S` 另存为
- `F5` 刷新设备
- `Ctrl++` / `Ctrl+-` 修改响应范围 / 轮盘半径时缩放当前圆圈

键位捕获、截图取点、输入文字时快捷键不生效，方便这些键当作待绑定键。

## 常见问题

- **提示“输入捕获不可用/无权限”**：执行 `sudo usermod -aG input $USER` 后注销重登，或用 `sg input -c './启动.sh'` 临时运行（仅 Linux）。
- **连接控制失败**：确认 `adb devices` 能看到设备，且 scrcpy-server 路径存在；在左栏手动指定 scrcpy 目录。
- **按键没反应**：① 看顶栏 `映射: 开/关` 是否被关了（日志有记录）；② 看引擎状态里“被放弃”是否为 0；③ 在别的窗口待过一会儿的话，按一次键会自动重新确认坐标空间。
- **外接键盘没反应**：打开 [诊断] 看设备清单里有没有它、以及有没有打不开的 `errno`。程序会定期重扫输入设备，插上后最多等约 2 秒就会自动接管，不必重启程序；拔掉再插上同样会自动恢复。
- **切窗口之后操作失灵，要重新开一次映射**：这是老版本的已知问题，已经修好（通道断开时会清空本地触点状态，重连时按当前按键状态重建）。若仍遇到，请把诊断日志级别改成 `debug` 复现一次，并导出诊断报告。
- **鼠标瞄准（FPS）没反应**：先看面板里的“生效条件自检”哪一项是 ✗；最常见的是尚未绑定 **[FPS 开关键]** 或尚未进入 FPS。注意**触摸板不能用于瞄准**（它没有相对位移轴），需要接鼠标或使用指点杆。
- **说不清原因的问题**：见上面的 [诊断与排错] —— 改 `debug` 级别复现一次，然后导出诊断报告。
- **画的圈看不清**：[外观] 里确认 **键位自动对比** 已开，再用 **键位显示亮度** 微调。
- **想打字**：按 F8 关闭映射即可。
