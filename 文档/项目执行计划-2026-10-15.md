# 项目执行计划 · scrcpy-pad（v2 · 2026-10-15）

> **性质**：规划交付物。实际执行由执行者按本文件的 wave/batch/block 推进；本文件是活体规划文档，执行期产生的**缓存索引**落入附录 C，block 状态变更在附录 D 勾选。
> **上游纪律**：执行期一切动作遵守 [AGENTS.md](../AGENTS.md)（C1–C10、三道门、变异验证、入口面矩阵、交付登记）与 [DSH工作纪律-证据优先工程协议.md](DSH工作纪律-证据优先工程协议.md)（三张清单、A/B 分级）。口径冲突取更严者。
> **用户总方针（按时间序）**：① 质量为主；② 微分化——拆成尽量多但不失控的小块，逐块实现、允许同批多块；③ **编译与验证不带 Linux 端**，只在写码时考虑跨平台兼容，以最快速度抢成果；④ **每次询问用户必须三件套**（来自什么问题 / 要解决什么问题 / 体现什么关键点）；⑤ **减少搜寻·阅读·替换代码的操作，多设计实验操作**。

## 0. 全局约束与落点

### G1 微分化（block / batch / wave）
- **block** = 最小验收单元：≤0.5 人日、单一文件面、独立通过条件。
- **batch** = 一次执行窗口：同文件面（或互不冲突文件面）的 1~k 个 block，**共用一次三道门**。
- **wave** = 时间窗：batch 的排序层；跨 wave 必须先过门再开工（AGENTS.md §3.6 并发纪律）。
- 全计划 **53 block / 20 batch / 7 wave**；关键路径与唯一硬外部依赖见 §2。

### G2 验证去 Linux 化（用户 2026-10-15 决定）
- **门禁只跑 Windows 宿主三道门**：`cargo fmt --check`、`cargo test --bin scrcpy-pad`、`python ci/clippy_diff.py`（与 `ci/clippy-baseline.txt` 零差异）。**删除**一切 WSL/Linux `cargo check` 步骤与验收项。
- **写码时跨平台兼容 checklist**（不验证、只约束写法）：
  1. windows-sys / Win32 调用只出现在 `#[cfg(windows)]` 面内；平台中立模块（keymap/engine 纯函数、sim）保持中立。
  2. 新增 `cfg` 分支必须双侧都有代码路径（Linux 侧允许 `unimplemented!`-free 的空实现/既有实现，不允许编译死）。
  3. 不引入仅 Windows 存在的**第三方 crate 特性**到中立依赖面。
- **债务登记 D-L1**：Linux 交叉编译验证整体推后；**偿还点 = 下次重建 linux 包之前必跑一次 WSL `cargo check --all-targets`**（与 AGENTS.md §6.3 过期包声明联动：linux 包继续显式标"过期，停留于 V2-3 交付"）。

### G3 询问三件套协议（用户 2026-10-15 决定）
- 执行期**任何**对用户的询问（拍板、B 级验收请求、中途求助）必须以**询问卡**形式给出三字段：
  - **[来自什么问题]**：源 block / 源证据（file:符号 或 文档:行）/ 源事故或源遗留。
  - **[要解决什么问题]**：该回答解锁哪个 block 的哪个决策；不答会停在哪。
  - **[体现什么关键点]**：对应哪条纪律/原则/风险（引用 AGENTS.md 或协议条款号）。
- 无三件套的询问，用户有权拒答；执行者不得以"顺带问一下"绕过。
- 本计划的全部待确认项已预写成询问卡（§10 Q1–Q9），执行期直接复用、不重拟。

### G4 实验优先 + 读/改预算（用户 2026-10-15 决定）
- 每个 block 指令前缀预算记号 `[读≤a 改≤b 验≥c]`：a = 定位/阅读操作上限，b = 代码编辑点上限，c = **实验操作下限**（实验 = 不改语义地产出证据的动作）。
- **实验菜单**（优先于读码/改码）：bench 注入矩阵、`--mask-selftest` 像素断言、`sim::replay` trace 回放、`raw_probe()` 探针实跑、变异运行（临时改→跑→还原）、**临时目录**配置实验（绝不碰用户配置，AGENTS.md §3.5）、trace/诊断日志解析测量、A/B 盲测协议、启动烟测+残留检查。
- **缓存索引**：R1/U1/U2 三个 block 的产出（符号表/规范索引/页面矩阵）落附录 C；其后 block **命中缓存不计读预算**，禁止重复全仓搜索（违者交付登记记一笔）。
- 超预算须在交付登记写一句理由；连续两个 block 超读预算 ⇒ 停止读码、转建仪表（AGENTS.md §2 Step3 同构）。
