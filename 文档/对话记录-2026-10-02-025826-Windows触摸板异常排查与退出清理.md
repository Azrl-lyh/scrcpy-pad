# Windows 触摸板异常排查与退出清理

- 记录时间：2026-10-02（Asia/Shanghai）
- 范围：Android 主程序 Windows 输入/光标清理；未修改 HarmonyOS 端。

## 用户反馈

Windows 触摸板出现短促点按不灵敏、滑动需要先移动一小段距离才恢复正常；怀疑 scrcpy-pad 退出时没有恢复系统设置。

## 代码审计结论

- 程序没有写入触摸板驱动设置、注册表或鼠标加速参数。
- 唯一会修改全局 Windows 状态的是 FPS 指针消隐：临时用 `SetSystemCursor` 替换系统光标方案，退出时用 `SPI_SETCURSORS` 恢复。
- 低层键鼠钩子只在输入捕获层安装，钩子回调本身不阻塞，但退出时原先没有等待钩子线程完成 `UnhookWindowsHookEx`。

## 已实施修复

- `Capture` 增加 Windows hook 线程句柄。
- 退出时先向 hook 消息线程发送 `WM_QUIT`，再有界等待钩子线程卸载；超时也不会卡死主进程。
- `eframe::run_native` 返回后再次兜底恢复系统光标方案。
- 恢复系统光标失败时记录诊断日志。
- 验证关闭主窗口后进程会立即退出，不再留下低层键鼠钩子。

## 验证

- `cargo fmt --all -- --check`
- `cargo check --bin scrcpy-pad --offline`
- `cargo test --bin scrcpy-pad --offline`：81 个测试全部通过
- Windows 主窗口关闭：`HasExited=True`
- Windows 与 Ubuntu 20.04 / glibc 2.31 Linux 发布包已重新构建

## 备注

如果系统在旧版本异常强杀后仍残留异常，建议先彻底结束所有旧的 `scrcpy-pad.exe` 进程并重启一次 Windows；新版本启动/退出会主动恢复系统光标方案。
