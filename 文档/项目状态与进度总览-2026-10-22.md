**原计划**：W1-1 事件时间戳 / W1-2 Windows Raw Input / W1-3 位移合并器与背压 / W1-4 钩子心跳自愈 / W1-5 键盘·滚轮保真。

**方向变化（重大，必须记住）**：**W1-2 期间发现原依赖 `rdev 0.5.3` 是一个定时炸弹，改用自装低级钩子**。

- **原计划**：继续用 `rdev` 的 `listen()` 做键盘鼠标捕获。
- **为什么改**：`rdev 0.5.3` 的回调在调用我们的闭包**之前**，会对每个 `KeyPress` 调 `Keyboard::get_name()` → `GetForegroundWindow` + `AttachThreadInput` + `ToUnicodeEx`。`AttachThreadInput` 是**同步附着到别的线程的输入队列**，对方不泵消息就阻塞；而 Windows 低级钩子有硬时限 `LowLevelHooksTimeout`（默认 **300 ms**），超时的事件被**静默丢弃**，反复超时还会把钩子**静默摘掉**。
- **改成什么**：自装 `SetWindowsHookExW(WH_KEYBOARD_LL)` + `SetWindowsHookExW(WH_MOUSE_LL)` + Raw Input 双通道。实测落点：`src/capture.rs:4410`（`SetWindowsHookExW(WH_KEYBOARD_LL, …)`）、`:4422`（`WH_MOUSE_LL`）；导入表在 `src/capture.rs:3365-3366`（`GetRawInputData` / `RegisterRawInputDevices` 等）与 `:3376`（`SetWindowsHookExW`）。**`Cargo.toml` 现已无 `rdev` 依赖**（本轮实测确认）。理由原文写在 `src/capture.rs:7-19` 的头注释里。
