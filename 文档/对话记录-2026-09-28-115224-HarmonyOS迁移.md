# scrcpy-pad HarmonyOS 迁移记录

- 记录时间：2026-09-28 11:52:24 +0800

- 开发环境：DevEco Studio `6.0.2.640`

## 本轮目标

把当前 `scrcpy-pad` 迁移为适用于 HarmonyOS 6 及以上手机的独立原生分支：

- 不兼容 Android 体系鸿蒙。
- 不兼容 HarmonyOS 4/5。
- 保留仓库根目录的 Windows/Linux 桌面版。
- 使用 HarmonyOS 原生 Stage 模型，优先 ArkTS/ArkUI。

## 技术结论

现有桌面程序依赖 Windows/Linux 全局键鼠钩子、ADB、scrcpy-server 和跨设备 TCP 控制，不能直接作为手机本机应用运行。HarmonyOS 分支因此采用：

1. `AccessibilityExtensionAbility` 接收实体键。
2. 无障碍能力声明 `gesture` 与 `keyEventObserver`。
3. ArkTS 映射引擎复刻桌面版的 `Held`、`FingerPool`、轮盘状态和 FPS 独立状态。
4. `AccessibilityExtensionContext.injectGesture` 将动作转换为触摸路径。
5. 手机端 ArkUI 控制台提供映射总开关、轮盘模式、FPS 开关/开关键/临时退出键与核心自检。

## 已落地

- 新建 `harmonyos/` Stage 工程，`bundleName = com.azrl.scrcpypad`。
- `targetSdkVersion` 与 `compatibleSdkVersion` 均为 `6.0.2(22)`。
- 只声明 `phone` 设备类型。
- 接入无障碍扩展入口和桥接层。
- 迁移经典/灵敏轮盘算法，默认经典。
- 灵敏模式严格按轴判断，左右与上下不冲突。
- 迁移 FPS 独立开关、临时退出键和 `fpsOnly` 模型；FPS 不依赖映射总开关。
- 增加物理按键权威快照、漏抬清理、模式切换全量对账和服务断开清理。
- 增加 Preferences 持久化：总开关、轮盘模式、FPS 开关键/临时退出键和点按绑定重启保留。
- 增加手机端点按键位编辑，可新增/删除点按动作并标记“仅 FPS”。
- 无障碍手势注入改为串行队列，避免长按窗口重入。
- 增加应用内核心状态机自检，覆盖自动重复、FPS 独立开关、灵敏轮盘与漏 KeyRelease 自愈。
- HAP 已在本机完成 debug/release 编译；当前无 HDC 真机连接，安装级验证待设备接入。

## 平台限制

- 普通第三方应用无法申请 `ohos.permission.INJECT_INPUT_EVENT`，该权限级别为 `system_core`。
- `ohos.permission.SYSTEM_FLOAT_WINDOW` 为 `system_basic`，不能作为普通应用全局悬浮窗方案。
- 无障碍 `GesturePath` 只提供完整路径注入，不具备公开的独立 DOWN/MOVE/UP 控制。
- 多指同时注入、无限时长长按、全局光标锁定不能保证复刻桌面版体验。
- 鼠标按键、滚轮和相对位移在无障碍扩展中的可见性需要在 HarmonyOS 6 真机验证。

## 验证

已执行：

```powershell
hvigorw --mode module -p product=default -p module=entry@default assembleHap --no-daemon
```

结果：`BUILD SUCCESSFUL`。

API 22 中 `injectGesture` 与 `injectGestureSync` 都会被编译器视为弃用，但仍是普通应用可用的无障碍手势接口。这里选择异步 `injectGesture` 并串行排队，避免同步接口阻塞到手势结束、推迟 KeyRelease；普通应用仍没有多指或独立 DOWN/MOVE/UP 的等价公开接口。

## 2026-09-29 目标纠偏

用户明确说明最终目标不是把 `scrcpy-pad` 迁移成手机应用，而是保留电脑端产品形态，让 Windows/Linux 程序通过 HDC 连接并控制 HarmonyOS 6+ 手机，达到类似 Android scrcpy 的效果。

因此拆为两条产品线：

- `harmonyos-pc/`：电脑端主产品线。基于 HDC、设备侧 `uinput` 和设备侧 `uitest screenCap`；后续接回现有 scrcpy-pad 的键位、轮盘和 FPS UI。
- `harmonyos/`：可选的手机端辅助应用。适合蓝牙/USB 键盘直接连接手机时使用，与电脑端主链路独立。

已从 OpenHarmony 源码确认：

- `uinput -T -d/-m/-u` 支持独立触摸 DOWN/MOVE/UP，最多三指。
- `uinput -K` 支持键盘按下、抬起、长按和文本。
- `uinput -M` 支持鼠标按键、移动、拖动和滚轮。
- `uitest screenCap -p <path>` 可以抓取屏幕，再通过 `hdc file recv` 拉回电脑。
- HDC 提供 `shell`、`fport/rport`、文件传输与持续连接能力。

独立辅助应用包已生成到 `release/harmonyos-companion/`。
