# 第一部分：初版实现

## 需求（用户原文要点）

1. **主题切换正式开工**：
   - 现有界面风格记为「默认」；
   - 新增「**鸿蒙**」：仿参考 App 的 UI，**切换要关闭一下 UI 再打开**，确保完全切换完毕（"像"即可，不追求面面俱到）；
   - 新增「**可视化**」：键位（单）显示时画一张**标准美式键盘**（含小键盘），被设置的键亮起、键位立体；点击空闲键位 = 截图取点，键盘下方出现操作栏，内容与现有 UI 一致（撤销/保存/取点/取消取点都要在）；组合键选中颜色做区分，未选中的键立体接近透明；摇杆同样按颜色区分；**FPS 单开一页**；虚拟键盘右方画**虚拟鼠标**（同套设置）；**取点中虚拟键盘相应位置亮起**；左栏中部改为 **键位组合 / 外观 / 诊断** 三张标签页（默认键位组合），夹在配置与 scrcpy 管理之间；日志位置、截图取点位置、透明度、四种配色都不变；
   - **记住主题**：下次启动沿用上次选择的风格。
2. **功能要"多加"而不是"选择"进去**：新交互建立在既有能力之上，旧的列表编辑一条不丢。
3. 太消耗精力的打磨部分可只留接口 + 注释，交给下一个更便宜的 AI。

## 已实施

### 1. 风格枚举与持久化（`theme.rs`）

- 新增 `UiStyle { Default, Harmony, Visual }`（`label()` / `ALL`），并把它作为 `Look.style` 字段（`#[serde(default)]`）—— 老配置缺字段即"默认"，观感与旧版逐一致。
- 新增 `pub mod harmony` 卡片配色（取自参考 App 的 ArkTS 样式）：`BG #10131A`、`CARD #171D28`、`BTN #283244`、`PRIMARY #0EA5E9`、`INPUT #0E131C`、`CARD_ROUND 12` 等。
- `apply_style` 按风格取"面板底 / 弹窗底 / 圆角 / 控件底 / 输入底"；**语义色仍由配色预设（Preset）决定** —— 风格与配色是两个正交维度，任意组合都保留。
  （注：鸿蒙配色与布局在第二部分被整套返工。）

### 2. 切换即"关一下再打开"（`app.rs` + `main.rs`）

- `PadApp::request_style_restart()`：写 `look.json` → 置 `STYLE_RESTART` 原子位 → `ViewportCommand::Close`。
- `main.rs`：`run_native` 外包一层 `loop`，返回后查 `take_style_restart()`，为真则**立刻用新风格重开窗口**。
- `take_style_restart()` 用 `swap(false)`「取走即复位」，并配单测，防止正常退出后出现"幽灵重启"。
- 因为风格随 `Look` 写进 `look.json`，重启后 `load_look_cache()` 自然读回 —— **"记住上次的主题"是这条链路的副产品**。

### 3. 虚拟键盘 / 虚拟鼠标组件（`keyboard.rs`，新增文件）

- 标准美式全键盘：F 行 / 数字行 / 三行字母 / 修饰键行（主区 17 单位）+ 导航区（3 单位）+ 小键盘（4 单位，`+` 与 Enter 跨两行，用 0.25 单位的占位网格定位）。
- `show_keyboard` / `show_mouse` 返回本帧被点击的键码（与全局捕获同一 evdev 码空间；鼠标 左272/右273/中274/侧275·276/滚上277/滚下278）。
- `pulse_mask` 实现"取点中呼吸闪烁"。
- **修掉一个真实布局 bug**：`TOTAL_UNITS` 原为 23.55，而布局实际 24 单位，导致小键盘最右一列被画到滚动区外裁掉；现修正为 `17 + 3 + 4`，并加单测锁定"总宽常量 = 三块之和"。

### 4. 可视化风格的点键取键（`app.rs`）

- `ui_vk_area`：一次性预扫描配置建"键亮表"（`vk_lights`，绘制闭包期间不再碰配置锁）→ 画键盘/鼠标 → 分发点击 → 渲染操作栏。
  - **点空闲键**：新建草稿并**立刻进入截图取点**（`begin_pick(CoordSlot::NewBind)`），操作栏出现 [取消取点]；取点中该键呼吸闪烁。
  - **点已设置的键**：`VkSel` 选中（加亮 + 白描边），操作栏显示**与该键在列表里同一套**编辑器（`ui_bind_row`）—— 撤销/保存/取点/转长按/改范围/仅FPS/删除全都保留；先点 [取点] 再按老流程操作也可以（两种顺序都行）。
- 键亮语义色：键位=绿、仅FPS=橙、摇杆方向=青/品红（永久/临时）、组合键与切换键=蓝、FPS 瞄准三键与总开关键=红。
- 标签页：右栏 = 键位 / FPS设置 / 其他功能（摇杆并入键位页）；左栏中部 = 键位组合 / 外观 / 诊断（**默认键位组合**）；`tab_button` 统一成"浏览器标签页"式方形按钮（不立体、大小不变）。
- 鸿蒙风格当时用 `card_if` 把左栏配置区与日志区包成圆角卡片（**第二部分已改为独立布局**）。

# 第二部分：返工（用户逐条打回）

## 用户反馈（原文要点）

1. 立体按键效果不满意 → 要**老式机械键盘**的外观；空键位至少要"跟背景有不一样的透明度"、底色稍深；如果透明度接近全透明，就要**额外画一个鲜艳一点的框**。
2. **切换完另一套键位后，实体按键消失了，所有的一切都变成跟默认一个效果**（功能回归）。
3. FPS 界面也要能显示普通键位的映射 —— "他们两个一样，能显示的部分一样，只是 fps 默认只显示 fps 独有的键位罢了"。
4. "鼠标瞄准（开发中）"这个折叠栏不要了，**直接解开、放出来**。
5. 逻辑错误要按逻辑修，不要"因为跑不通代码就胡乱改代码"。
6. 鸿蒙 UI 必须**按两张截图（`harmonyos-pc` 的 HDC UI）基本完全重新设计**，不是给默认界面换卡片底色。

## 根因与修复

### ① 切组合后"一切变回默认"（#2）—— 根因是风格被 YAML 覆盖

- **根因**：`apply_profile_switch` / `select_scheme` / 切换键等路径都会用配置里的 `Profile` 整体替换 `Shared::profile`（`install_config`）。YAML 的 `look` 里**没有 `style` 字段**（反序列化缺省 = `Default`），于是主题被冲掉 → 布局回到"默认"，虚拟键盘"消失"，且**没有任何报错或日志**。
- **修复**：风格改为**界面级持有**：
  - `PadApp.style: theme::UiStyle`（启动时从外观缓存取一次）；
  - `ui_style()` 读它，不再读 `profile.look.style`；
  - 新增 `stamp_style()`：每帧把 `self.style` 盖回共享配置（值不同才写），因此**任何**换组合的路径都无法把主题带走；
  - `request_style_restart()` 同时更新 `self.style`；外观面板里的风格选择器改成"选到临时变量 → 交给 request_style_restart"，不再直接改 `profile.look.style`。

### ② 老式机械键盘 + 空键位可见（#1）

`keyboard.rs`：

- `KeyLook` 增加 `side`（键帽侧壁）；`KeyLook::idle()` 改为**半透明灰键帽**：`fill a=132 / side a=224 / stroke a=216 / text a=232`（旧版 14/46/110 几乎看不见）。颜色固定不随底色调 —— 半透明中灰在浅色与深色界面上都能与背景形成差别。
- `draw_key` 改为四层：**裙边（下沉 depth 并外扩 0.7）+ 顶面 + 内圈倒角（1px 白 52 高光）+ 鲜明外框（1.2px）**。
- `show_keyboard` 新增**深色机身底盘**（整张键盘坐在一块 12px 圆角的深灰机身上，带 1px 亮描边）与四周留边（8/10/12px），键帽因此"嵌在壳里"。
- `show_mouse` 用同一套语言（深色壳体 + 鲜明描边 + 键帽画法）。
- 单测 `idle_keys_are_visible_but_translucent` 锁死"最低可见度"（fill alpha 60..200、stroke ≥180、side 比顶面更实）。

### ③ FPS 页显示能力对齐（#3）

- 新增 `VkFilters { binds, combos, wheels, fps }` 与两套默认值：`KEYS_PAGE`（全开）/ `FPS_PAGE`（只开 fps）。
- `vk_lights(filters)` 统一成一份逻辑：普通键位看 `binds`、"仅 FPS"键位看 `fps`、摇杆看 `wheels`、组合键与切换键看 `combos`、瞄准三键看 `fps`、总开关键始终亮。
- `ui_visual_fps` 现在也渲染同一组四个勾选（文案一致），`ui_vk_area` 按页取对应的 `VkFilters`。
- 约束保留：FPS 页仍**只能编辑** FPS 相关键（`vk_sel_is_fps`）。
- 单测 `vk_filter_defaults_match_the_two_pages` 锁住"键位页全显示 / FPS 页默认只看仅 FPS"。

### ④ 鼠标瞄准折叠栏去掉（#4）

`ui_aim` 从 `CollapsingHeader::new("鼠标瞄准(FPS)（开发中）")` 改为直接 `heading + 开发中说明 + ui_aim_body(...)`，三个调用点（默认 FPS 标签页 / 可视化 FPS 页 / 鸿蒙 FPS 页）自动生效。

### ⑤ 鸿蒙风格：照 HDC UI 重新设计整套界面（#6）

配色（`theme::harmony` 全部换成 HDC 应用的数值，取自 `harmonyos-pc/src/bin/gui.rs`）：

| 名称 | 值 | 用途 |
|---|---|---|
| `BG` | `#F4F7FB` | 页面底 |
| `CARD` | `#FFFFFF` | 卡片 / 面板底 |
| `BTN` / `INPUT` | `#EEF3F9` / `#ECF1F7` | 控件底 / 输入框底 |
| `LINE` | `#DEE5EE` | 细描边 |
| `TEXT` / `MUTED` | `#182230` / `#69778B` | 正文 / 次要说明 |
| `PRIMARY` | `#2384FF` | 主色(蓝) |
| `OK/WARN/DANGER` | `#16A34A` / `#D97706` / `#DC2626` | 语义色 |

`apply_style`：鸿蒙强制走**浅色** Visuals（不受深色预设影响），控件悬停/按下用 `PRIMARY.gamma_multiply(0.15 / 0.5)`、控件底 `BTN`、`override_text_color = TEXT`、`window_stroke = LINE`，间距/内边距/交互高度/滚动条宽度与字号**直接照 HDC 的 `configure_style`**（9/8、12/7、30、7）。`Look::theme()` 在鸿蒙下把 ok/warn/danger/accent/muted 换成 HDC 那套（浅色底可读）。

## 留给下一位

1. **UI 交互只能人工验证**：点键 → 取点 → 操作栏、切换组合后主题保持、FPS 页勾选切换，本轮只做了"渲染 + 启动 + 宽度实测"与纯逻辑单测。
