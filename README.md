## 安装注意

有关scrcpy，本仓库附带提供在windows或linux下可用的版本的压缩包，如果不想花时间找别处下载或对新版本不作要求，只需要下载本仓库里提供的压缩包，并将他解压到主程序（即scrcpy-pad-windows.exe，或scrcpy-pad-linux)同目录下即可。
注意，所谓“同目录下”，指的是scrcpy-pad程序，和以scrcpy-xxxx为名的文件夹放在同一目录下。
如果scrcpy找不到scrcpy，你也可以手动选择，在程序中选择“寻找scrcpy”等按钮，按照提示从相应目录选择即可。直到scrcpy，scrcpy-server和adb都被寻找到即可。
本站scrcpy下载包就在仓库内，名为：
windows版本：scrcpy-win64-v3.3.3.zip
linux版本：scrcpy-linux-x86_64-v3.3.3.tar.gz
作者不保证频繁更新之。

如果你是windows用户，你只需要下载本仓库中的scrcpy-pad-windows.exe，和scrcpy（windows版本），解压scrcpy到程序同目录下后双击运行即可。  
如果你是linux用户，你需要下载本仓库的scrcpy-pad-linux（没有.exe)和scrcpy（linux版本），之后运行以下命令修改权限：
``` 
sudo usemod -aG input $USER
```
运行后输入管理员密码，注销重新登录即可。

之后就可以成功运行了。

# scrcpy-pad

当前版本：**0.1.2**

基于 [scrcpy](https://github.com/Genymobile/scrcpy) 的键鼠映射工具，用于执行在电脑上把键盘按键映射为手机屏幕上的触控操作。

```
键盘/鼠标 ──► ┌─────────────┐      ┌──────────────┐      ┌──────────┐
              │  scrcpy-pad │ ───► │ scrcpy-server│ ───► │   手机    │
              │  (映射引擎)  │ TCP  │ (仅控制通道)  │ adb  │  游戏画面 │
              └─────────────┘      └──────────────┘      └──────────┘
                    画面由 scrcpy 本体窗口显示，与本程序互不干扰
```

## 1. 功能

### 1.1 动作类型

| 动作 | 说明 |
|---|---|
| 点按 | 按键触发一次触控点击。可设置触点持续时长；时长为 0 时表示按住不松手，直到再次按下同一键才抬起 |
| 长按 | 按住键盘期间手机触点保持按下，松开即抬起，实时跟随。与点按可一键互转 |
| 滑动 | 按键触发一次滑动。可分别设置起点、终点、时长、速率曲线与运动轨迹 |
| 系统键 | 注入 Android 系统按键（如返回 = 4、主页 = 3） |

### 1.2 轮盘（虚拟摇杆）

- 四个方向键（默认 WASD）驱动一个虚拟摇杆，支持八方向，松开自动回中。
- 临时轮盘：为轮盘设置"启用键"后，该轮盘仅在启用期间生效；启用期间其方向键的其它绑定自动让位，其余键位不受影响。支持"按住启用"与"再按切换"两种模式。

### 1.3 滑动曲线与轨迹

速率曲线（决定滑动过程中沿路径的进度分配）：

| 曲线 | 参数 | 说明 |
|---|---|---|
| 默认（匀速） | 无 | 进度随时间线性变化 |
| 加速曲线 | 幂次（默认 2） | 慢起快止 |
| 减速曲线 | 幂次（默认 2） | 快起慢止 |
| 钟形曲线 | 幂次（默认 3） | 起止慢、中间快 |
| 贝塞尔曲线 | x1, y1, x2, y2（默认 0.42, 0, 0.58, 1） | 即 CSS ease-in-out |

选择曲线后可点"设置..."调整参数，窗口内会同步绘制该速率函数的曲线图。

运动轨迹（决定路径的空间形状）：

| 轨迹 | 说明 |
|---|---|
| 默认（条形） | 起点到终点的直线 |
| 方形 | 起点为左上角、终点为右下角，沿矩形边界顺时针一圈 |
| 圆形 | 默认起点与终点为直径两端；可切换为"视为圆心"（起点为圆心、终点确定半径），并可另设"出发点"角度 |

### 1.4 响应范围

每个点按/长按键位有一个圆形响应范围（默认半径 35.2 像素）。点"修改响应范围"后该圆圈变黄，用 `Ctrl++` / `Ctrl+-` 缩放，或直接在截图上拖动圆圈；点"完成"退出。缩放按固定比例逐步进行，除浮点精度外不设上下限；缩到默认值附近时自动复位为默认半径以保持精度。

### 1.5 键位浮层

所有键位与轮盘叠加显示在手机截图上：绿圈 = 点按，橙圈 = 长按，黄圈 = 修改响应范围中/新增草稿，蓝线 = 滑动轨迹（内部半透明填充），青圈 = 永久摇杆，品红虚线圈 = 临时摇杆。可按 全部/仅键位/仅摇杆/永久/临时 过滤显示。

### 1.6 其它

- 总开关键（默认 F8）：随时开关映射。关闭时自动释放所有触点与系统键，不会卡键。
- 截图取点：截取手机屏幕后，点击图像完成坐标设置。新增点按/长按时，取点后若尚未指定按键，会立即进入按键捕获状态。
- scrcpy 管理：scrcpy.exe / scrcpy-server / adb.exe 任填一个，其余留空会自动从同目录补齐；也可自动寻找或手动指定，并可测试可用性。
- scrcpy 参数助手：参数框旁 `...` 打开常用参数列表，含中文说明、使用示例、双击临时编辑与一键加入。
- 启动预设：启动按钮旁下拉可选 无 / 2k / 4k / 1k / 720p / 不使用音频输出 / 使用音频输出。分辨率预设会先重置为初始参数再叠加 `--max-size`；音频预设直接在现有参数上增删 `--no-audio`。
- 配置管理：保存、另存为、选用已有 json、在指定路径新建、校验当前 json 合法性。
- 撤销/重做：顶栏按钮或 Ctrl+Z / Ctrl+Y。
- 保存日志：导出设备型号、Android 版本、分辨率、主机环境与运行日志。
- 多点触控：轮盘与按键各有独立触点，可同时进行；普通按键之间互不干扰，最多 5 键同时按下。

## 3. 编译与运行

```bash
git clone https://github.com/Azrl-lyh/scrcpy-pad.git
cd scrcpy-pad

```

产物：`target/release/scrcpy-pad`（Linux）/ `target/release/scrcpy-pad.exe`（Windows）。

## 4. 使用步骤

1. 手机开启 USB 调试并连接电脑。
2. 启动 scrcpy-pad。程序会自动寻找 scrcpy 并检测版本，左栏显示结果。
3. 顶栏下拉选择设备，点 **连接控制**（建立注入通道，成功后显示绿点）。
4. 点 **启动 scrcpy**，弹出手机画面窗口。
5. 点 **截取手机屏幕**，游戏画面进入程序。之后配置键位与轮盘。
6. 按 **F8** 开启映射；再按 **F8** 关闭。

### 4.1 配置轮盘

1. 四个方向按钮逐个点选后按物理键（默认 WASD）。
2. 点 **取圆心**，在截图上点击游戏摇杆中心。
3. 拖动半径数值调整范围。
4. 如需临时摇杆，点该行的 **启用键** 捕获一个键，并选择"长按启用"或"再按切换"。

### 4.2 配置按键

1. 在"新增"行选择类型（点按/长按/滑动/系统键）。
2. 点"未绑定"按钮，按下要绑定的物理键。
3. 按类型设置参数：
   - 点按/长按：x、y、响应范围；点按另有触点时长（0 表示按住切换）。
   - 滑动：分别点 **取起点** 与 **取终点** 在截图上取点，设置时长、曲线、轨迹；曲线参数点 **设置...** 调整。
4. 点 **添加**。点按/长按型添加后会自动进入取点状态，直接在截图上点击目标位置即可；取点后若该键尚未设置按键，会立即进入按键捕获状态。
5. 已添加的键位可在行内直接修改参数：改写按键、调整数值、**取点**（仅改坐标）、**转长按/转点按**、**修改响应范围**、**删除**。

### 4.3 保存与分享配置

- 默认配置文件：`~/.config/scrcpy-pad/profile.json`（Windows 为对应的用户配置目录）。
- **保存配置**：写入当前指向的配置文件。
- **另存为...**：导出为独立 json。
- **选用配置...**：选择任意 json 作为当前键位，加载前会校验合法性。
- **新建配置...**：在指定路径创建一份默认配置并切换过去。
- **检测当前 json**：校验当前配置文件是否符合格式要求。

### 4.4 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 保存当前配置 |
| `Ctrl+Shift+S` | 另存为 |
| `F5` | 刷新设备列表 |
| `Ctrl++` / `Ctrl+-` | 修改响应范围时缩放当前圆圈 |

键位捕获、截图取点或输入文字时，上述快捷键不生效，以便这些按键可作为待绑定键使用。

### 4.5 Linux：映射时屏蔽原键

勾选"映射时屏蔽原键(grab)"后，映射开启期间键盘只对本程序生效，避免误触发系统输入。Windows 上此选项不生效。

## 5. 工作原理

- 启动一个 control-only 的 scrcpy-server（`video=false audio=false control=true`，独立 scid），仅作为触控注入通道，与 scrcpy 画面窗口互不干扰。
- 直接实现 scrcpy 控制协议（触控消息 32 字节大端序列化），事件驱动，与官方客户端延迟同级。
- 全局键盘捕获：Linux 用 evdev（`/dev/input`），Windows 用 rdev 低级钩子。
- 键码统一为 Linux evdev 码空间，配置文件在两平台通用。
- 文件对话框：Linux 用 xdg-desktop-portal，Windows 用 Win32 原生。

## 7. 常见问题

**提示"输入捕获不可用 / 无权限"**
执行 `sudo usermod -aG input $USER` 后未重新登录。注销重登，或用 `sg input -c './启动.sh'` 临时借组运行。

**连接控制失败**
确认 `adb devices` 能看到设备，且 scrcpy-server 路径存在。找不到时在左栏手动指定（Linux/Windows 的斜杠方向均可）。

**Windows 上 scrcpy 画面正常，但顶栏一直"无设备"**
列设备使用程序自己的 adb；官方 Windows 发行包的 adb.exe 与 scrcpy.exe 同目录且不在 PATH 中。在左栏 **scrcpy 管理** 中浏览选择 scrcpy.exe（或 scrcpy-server / adb.exe 任一），其余会自动补齐并刷新设备。

**开了映射但按键没反应**
确认总开关键状态为"开"；确认该键已绑定；Linux 下确认程序以 input 组权限运行。

**游戏时想打字**
按 F8 关闭映射即可。

**临时轮盘的方向键平时还能用吗**
能。未启用期间方向键的普通绑定照常生效；启用瞬间引擎会自动释放冲突触点。

**按住一个键再连点另一个键时，另一个键不响应**
当前版本已支持最多 5 键并发，且点按为抢占式触发，任意速度的连点都会完整触发。若在模拟器上仍无效，通常为该模拟器的多点触控能力限制，可用真机对比确认。

- 新增响应范围设置：点按/长按键位可设置圆形响应范围，默认半径增大至 35.2 像素。"修改响应范围"进入黄色修改态，`Ctrl++` / `Ctrl+-` 乘性缩放或直接拖动圆圈，缩回默认值附近自动复位以保持精度，除浮点精度外不设上下限。
- 滑动功能重构：改为起点/终点两点取点（两个按钮），新增速率曲线（默认匀速/加速/减速/钟形/贝塞尔）与运动轨迹（默认条形/方形/圆形）。圆形可切换"视为直径/视为圆心"并另设出发点。
- 滑动曲线支持参数编辑：加速/减速/钟形调整幂次，贝塞尔调整 x1,y1,x2,y2（默认 0.42,0,0.58,1，即 CSS ease-in-out），编辑窗口内实时绘制速率函数预览图。
- 截图上绘制滑动轨迹：边界着色、内部半透明填充，不影响截图内容识别；键位条目内直接显示并设置滑动时长。
- 取点流程修复：新增点按/长按取点后，若尚未指定按键会立即进入按键捕获状态；已添加键位的取点仅修改坐标，不再触发按键变更。取消取点时，若新增键位尚未设置则一并清除草稿圆圈。
- 点按时长支持设为 0：表示触点按住不松手，直到再次按下同一键才抬起。
- 版本号更新为 0.1.2。

### 2026-09-09

- 键位并发加固：按住一个键的同时连续点按另一键不再吞键；点按支持任意快速连点，最多 5 个键同时按下互不干扰。
- 添加点按/长按绑定后自动进入取点等待，无需再手动点 [取点]。
- 中央区改为横纵双向滚动，长内容不再被窗口裁掉。
- 配置文件支持重定向：选用配置…（使用已有）、新建配置…（在新路径创建空配置）、检测 json…（校验合法性）。
- 点按动作支持设置触点响应时长；长按转点按自动补默认值，点按转长按不保留该项。
- 顶栏 scrcpy 参数框旁新增 `...` 常用参数助手：参数列表、中文说明、使用示例、双击临时编辑、一键加入，附 scrcpy 官方 GitHub 链接。
- scrcpy 启动按钮旁新增参数预设下拉：无（默认 --stay-awake）/ 2k / 4k / 1k / 720p，以及不使用音频输出、使用音频输出。
